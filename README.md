# Uzbek English — Android Play Store Project

A native Android offline Uzbek ↔ English vocabulary and phrase app.

## Features
- English → Uzbek / Uzbek → English
- 100+ common words and phrases
- Word-by-word fallback
- Favorites and recent history stored locally
- Copy and share
- Android text-to-speech pronunciation
- In-app About and Privacy Policy
- No ads, accounts, analytics, network, location, camera, contacts or microphone permissions
- Target SDK 36

## Open
Open this folder in Android Studio and let Gradle sync.
